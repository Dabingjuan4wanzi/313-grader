# 部署"百度高精度 OCR"通道（一次免费配置，约 2 分钟）

网页（GitHub Pages / 手机）无法直接调用百度 OCR（浏览器跨域 CORS 会拦截）。下面的步骤用一个 **Cloudflare 免费的 Worker**，在云端帮你转发一次就可以。百度高精度识别免费额度足够日常判卷用。

整个流程三步：**① 领百度 OCR 免费额度 → ② 免费部署 Cloudflare Worker → ③ 网页里填 3 个值。**

---

## ① 拿百度云 API Key / Secret Key（免费）

1. 打开 <https://cloud.baidu.com/>，注册 / 登录并**实名认证**（必须）。
2. 搜索进入 **「文字识别」OCR** 产品页 → 「立即使用」/「领取免费额度」→ 选择「通用文字识别（高精度）」，按提示创建应用。
3. 创建后在 **应用列表 → 管理** 里能看到三个字段，只用到两个：
   - **API Key**（就是 client_id）
   - **Secret Key**（就是 client_secret）
4. 这两个值只填进你自己的网页里（存手机本地浏览器），注意保密。

> 免费额度：个人实名认证后一般有 **高精度版约 500 次/天**（不同时期政策可能变化），判卷足够用。

---

## ② 免费部署 Cloudflare Worker

1. 打开 <https://dash.cloudflare.com/> 注册（免费）。
2. 登录后左上选你的账号 → 进入 **Workers & Pages**。
3. 点 **Create application → Create Worker**。
4. 给 Worker 起个名字（如 `313-ocr`），会得到一个地址 `https://313-ocr.你的账号名.workers.dev`。
5. 点 **Edit code**，把本目录的 **`worker.js`** 里 `export default { ... }` 的**全部内容覆盖**进去。
6. 点右上 **Deploy**。
7. 打开刚部署的地址根路径，若显示 `{"ok":true,...}` 即成功。

---

## ③ 在网页里配置

1. 打开你的判卷网页 → 第 0 步设置 → 图片文字识别方式选 **「百度高精度（推荐）」**。
2. 填三项：
   - **Cloudflare 代理地址**：填 `https://313-ocr.你的账号名.workers.dev`（上面生成的地址）
   - **百度 API Key**：填第①步拿到的
   - **百度 Secret Key**：填第①步拿到的
3. 点「开始识别」。成功后图片会先到你自己的 Cloudflare Worker，再转发到百度完成高精度识别，返回的行文字会自动填入识别结果，并画上红框。

## FAQ

- **不想用 Cloudflare，只想电脑上测？** 电脑双击 `start-grader.bat`，手机连同一 WiFi 打开。此时 Cloudflare 代理地址可以填 `http://电脑IP:8080`（即本仓库 `server.py` 内置了同协议的 `/ocr` 接口），就不依赖外网代理。
- **报错"没有识别到文字"？** 多数是图片太模糊/光线不均，或当天免费额度用尽（百度会返回错误码）。
- **百度报 110 / token 失效？** 这是百度临时需要刷新，再点一次「开始识别」即可；必要时回到第①步重新领取额度。
- **隐私提醒**：图片和密钥会经过**你自己**的 Cloudflare Worker 再传给百度。请只给自己使用、别把代理地址公开给他人。
