未设置 Key

0设置（只需一次）

包括判卷用的 DeepSeek 密钥，和图片文字识别方式。全部存在你手机本地。

没有密钥？打开 platform.deepseek.com → API Keys 创建一个，充值几块钱够用很久。

内置识别：免费、无需配置、图片不出手机，首次下载识别模型约 8MB。自定义 API：填你自己的 OCR 服务。AI Studio：用百度 PaddleOCR 云服务（识别质量高，需中转）。

你的 OCR 服务需支持：向该地址 POST 上传图片（字段名 file / image 均可），返回 JSON 文本结果（RapidOCR、PaddleOCR 服务、百度 OCR 等常见格式都能自动识别）。若你的服务需跨域授权，请确认已开启 CORS。

AI Studio 服务端不允许网页直接访问，必须经中转。点「开始识别」时会自动从多个公共中转里挑能用的；找不到时会提示你。注意：使用公共中转时图片会经过该中转服务器。

1上传手写答案

选择一张你的论述题手写答案图片，拍清楚、光线好一点，识别更准。答案有多页请分次上传处理。

2识别手写文字

按第 0 步选择的识别方式处理：内置识别在你手机本地跑（免费）；自定义 API 则发送到你自己的 OCR 服务。

红色框内是按顺序识别出的文字，下面每一行对应一个框，可对照修改。

3填写题目

粘贴或输入本题的完整题目文字（如“论述 19 世纪中至 20 世纪初亚洲民族解放运动的三次高潮及意义”）。也可以拍照识别纸质题目。

4开始判卷

AI 将按你的 313 阅卷规则（40 分制）批改，输出：得分汇总、得分点覆盖对照、问题诊断、范文。每次约消耗几分钱余额。

使用说明
1. 首次使用先填 DeepSeek 密钥，并选好识别方式（内置免费 / 自定义 API / AI Studio）。
2. 上传手写答案图片 → 识别 → 逐行校对错字。
3. 填题目 → 开始判卷，等约 1~3 分钟出报告。
4. 内置识别最省事（免费、图片不出手机），推荐优先使用。
5. AI Studio（高质量手写识别）：在设置里填你的 Token，中转地址留空，点识别时自动挑可用中转。若自动中转全部不通，可换网络重试，或到电脑运行 start-grader.bat、手机扫码进局域网页面用。
你的图片、密钥、答案只存在本机（AI Studio 模式会把图片发到你的识别服务；使用公共中转时还会经过中转服务器）。
